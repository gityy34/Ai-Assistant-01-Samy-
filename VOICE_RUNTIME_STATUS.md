# Voice runtime checkpoint

Base voice integration uses sherpa-onnx 1.13.8 and checksum-verified Urdu Fasih and English Lessac Piper model packs. The APK bundles the models; the app performs no network download. Base voice playback is explicitly separate from reference-voice cloning. Cloning remains unconfigured. On-device output quality, RAM, heat and interruption behavior have not been verified. ARM64 only.
