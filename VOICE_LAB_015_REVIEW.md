# Voice Lab 0.1.5 review

This release separates text reading from reference-conditioned English cloning, with right-to-left Urdu-first controls, light/dark colors, cards, a persistent Play/Stop bar, accessible stacked voice choices and wrapped speed choices. A recording is not used by Base Voice.

Recording is guarded against double start/stop, shows seconds, auto-stops after 15 seconds, and is published as WAV only after the header is complete. A failed recording preserves the previous sample. Microphone/file errors are contained and resources are released. Import blocks conflicting operations, supports cancellation, caps bytes, validates mono 16kHz PCM and 3–15 seconds, and removes partial files on failure. Playback timeout accounts for selected speed. A frame-based near-silence pass caps pauses exceeding 750ms to 350ms and trims excessive edge padding; normal short pauses and voiced samples remain unchanged. Clone submission is disabled until English is selected.

Validation includes existing six native tests, two real Compose interaction tests (language/text retention, speed/voice selection, synthesis, Stop/restart, microphone record/save/replay), and two import failure/format tests. CI saves screen captures for visual inspection. Three new silence-pacing unit tests cover preservation of voiced samples and normal pauses. Android 36, large text and dark-mode capture are included. Results must be read from the final run, not assumed from implementation.

Known limits remain: PocketTTS is English-only; a changed reference changing the output does not establish perceptual similarity to a person's voice. Urdu pronunciation depends on the bundled Fasih/Aegis models; no higher-quality Urdu model has been validated in this release. This milestone reads provided text and does not provide LLM answers. No cloud fallback or automatic uploads are added.
